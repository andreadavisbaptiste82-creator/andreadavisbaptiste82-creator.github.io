# Upload this portfolio to GitHub Pages

This package is ready for the repository `andreadavisbaptiste82-creator.github.io`.

1. Open the repository on GitHub and select **Add file → Upload files**.
2. Unzip the package on your computer.
3. Upload the **contents inside** the `andrea-executive-portfolio-github` folder, including `index.html`, the other HTML pages, and the complete `assets` folder. Do not upload only the outer folder.
4. Commit the upload to the `main` branch.
5. In **Settings → Pages**, confirm that GitHub Pages publishes from the `main` branch and the repository root.
6. Wait a few minutes, then open `https://andreadavisbaptiste82-creator.github.io/` and refresh the page.

The Corporate page includes the Responsible AI prototype, Grace prototype introduction, leadership-perspective videos, strategic framework, résumé, AI Workforce Readiness Playbook, and Executive Value Profile. The K–12 page includes the Future Ready AI curriculum, grade-band videos, drone media, and downloadable resources.
